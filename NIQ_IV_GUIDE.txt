Your resume clearly states: "Built scalable Selenium frameworks (Data-Driven, POM, Hybrid) in Java for UI and RestAssured for API automation." This is a major selling point.

 Be ready to explain the architecture of your frameworks:

 Selenium WebDriver:
     Advanced Interactions: Be ready to discuss handling complex scenarios like dynamic web elements, hidden elements, frames, multiple windows/tabs, and synchronization issues (explicit waits, fluent waits).

     Explain how you used RestAssured for API testing.
